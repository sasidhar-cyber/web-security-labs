# ⚡ XSS — Cross-Site Scripting

## What is XSS?

Cross-Site Scripting (XSS) is a web security vulnerability where
untrusted input can be executed as JavaScript in a user's browser.

## Types

- Reflected XSS
- Stored XSS
- DOM-based XSS

## Learning Goals

- Understand how XSS works
- Identify unsafe input handling
- Learn proper output encoding
- Understand XSS prevention

> Practice only in intentionally vulnerable applications or systems you are authorized to test.
